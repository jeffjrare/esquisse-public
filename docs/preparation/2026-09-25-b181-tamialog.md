## Défauts observés avant correction

La [première proposition](2026-09-25-b181-tamialog/before-proposal.md) conserve
l'ordre demandé, le sélecteur et les trois nouveautés, propose une grille
responsive et de la copie FR/EN, et laisse le futur plafond à mesurer. Elle
identifie correctement les limites de l'audit (390 px mobile ; fold/overflow
rapportés, pas garantis par exit 0). Mais :

- **Elle change le résultat sur une fausse conclusion.** « L'avertissement n'est
  pas dans le tiroir » : la trace lit `spacing-confirm.tsx`, pas le rendu de
  `QuickLogSheet.tsx`. À ce même commit, celui-ci calcule `noticeSentence`
  (lignes 417–444), rend `data-spacing-notice` (642–645) et adapte l'action via
  `pressOverrides`. La confirmation modale est une autre voie, pas la preuve
  d'absence du fragment demandé. Le plan substitue pourtant cette modale.
- **Elle crée un prérequis utilisateur évitable** : rafraîchir SPEC ou accepter
  un écart, alors que le mandat fournit déjà les sources app des fonctions
  livrées. La lacune documentaire ne révèle pas une règle produit indécise.
- **Elle rachète du travail** : build landing, puis audits avec build implicite,
  répétition du même audit pour son format JSON, puis build workspace. Séparer
  le plafond de la livraison UI crée aussi une phase incomplète sous le budget.
- **Elle dépasse 900 mots** (1 214), avec un rapport d'investigation préalable.
  Elle affirme aussi un HEAD détaché sans Git : l'archive est hors dépôt.

La disposition « deux fragments dans la colonne droite » est recevable ; son
coût et la preuve multi-membre placée après le sélecteur restent à vérifier.
La traduction « formula bottles » perd la précision « en poudre ». Une garantie
de forme `satisfies Copy` ne prouve pas à elle seule la parité du sens.

## Correction du chemin chargé

La sortie native reprend l'annonce de `esq:plan`, le plugin est découvert et
la trace ouvre explicitement `plan/references/screens-and-manual-steps.md`.
Les modifications remplacent les consignes existantes dans cet entrypoint et
cette référence : lire le rendu de l'écran demandé avant de lui substituer une
autre surface ; documenter les lacunes de SPEC sans imposer son rafraîchissement ;
inspecter les builds imbriqués et réutiliser une mesure ; réserver la réponse
bornée au livrable demandé. **+43 mots nets**, sans nouveau rôle, framework,
checklist ou test de présence de prose.

Lecture contradictoire : une règle produit réellement non résolue exige toujours
l'autorité prévue par « Resolve blocking decisions ». L'autorisation du nouveau
placement ne permet pas de retirer le sélecteur ni d'inventer une posologie.
Une mesure après une modification du rendu reste nécessaire ; `--no-build` ne
permet pas de mesurer un `dist` périmé. Les propriétés/environnements distincts
et l'identité exacte des commandes de preuve restent préservés. Aucun contrat de
format, writer ou statut n'est changé ; la description README de plan reste vraie.

## Vérification locale et coût de reprise

Un seul `./scripts/audit.sh`, borne 180 s, exécuté en **26,66 s** : six contrôles
sur sept passent, dont la validation native du plugin. La suite produit a
**387 PASS / 5 FAIL**. Cause de cette vérification invalide : le lanceur de cette
session avait conservé `ESQ_TELEMETRY=off` des essais modèle. Les assertions
attendant la télémétrie active échouent et les hooks n'écrivent pas leurs fixtures.
C'est une erreur du lanceur d'évaluation, pas un défaut introduit par ces consignes.
L'[audit initial](2026-09-25-b181-tamialog/audit.txt) reste conservé comme échec,
avec ses [paramètres et empreintes](2026-09-25-b181-tamialog/audit-metrics.json).

Reprise limitée aux **cinq cas concernés**, via `--test-name-pattern`, après
retrait de cette seule variable, borne 60 s : **5/5 PASS**, en moins d'une seconde.
Les trois premiers échecs étaient nommés dans la sortie de l'audit ; les deux
tronqués sont identifiés par les seuls autres chemins concernés : le défaut
`telemetryOptedOut(undefined)` et le sous-processus du Stop héritant de l'environnement.
Aucun des 387 cas acquis ni des six autres contrôles n'est rejoué, aucun fichier
produit ou test n'est changé. [Commande et environnement corrigés](2026-09-25-b181-tamialog/audit-environment-recovery.json),
[sortie intégrale des cinq cas](2026-09-25-b181-tamialog/audit-environment-recovery.txt).
Ce résultat composite n'est pas présenté comme un audit initial 7/7 vert.

Une validation des registres renvoie [valid: true, aucun finding](2026-09-25-b181-tamialog/ledger-validation.json).
Les empreintes des deux propositions correspondent aux sorties retenues. Le coût
additionnel est une reprise locale de cinq tests, **aucun essai modèle**. Les seules
